# TP4 - Gestion des commandes

Application JavaScript qui relie clients, produits et commandes (JSON).

## Structure
- index.html, css/style.css
- data/ : customers.json, products.json, orders.json
- js/ : app.js, state.js, dataService.js, selectors.js, view.js

## Fonctionnalités
- Chargement de 3 fichiers JSON avec fetch/async/await
- Indicateurs dynamiques, recherche par client, filtres statut et catégorie
- Détail d'une commande (modal) avec totaux calculés

## Lancer le projet
Ouvrir le dossier avec VS Code et lancer Live Server sur index.html.
